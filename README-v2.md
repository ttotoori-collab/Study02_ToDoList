# Study02_ToDoList

브라우저에서 바로 실행되는 개인용 할 일 관리 앱이다. 하루 10~20개 수준의 할 일을 적어 두고, 카테고리로 나눠 보면서 완료 여부와 진행률을 확인한다.

서버도 계정도 빌드 도구도 없다. HTML 파일 하나를 브라우저로 열면 실행되고, 데이터는 브라우저의 localStorage에 남는다.

## 현재 상태

**요구사항 정의와 구현 계획까지 끝났고, 코드는 아직 없다.**

- [PRD.md](PRD.md) — 요구사항, 데이터 모델, 화면 설계, 완료 기준
- [PROMPTS.md](PROMPTS.md) — PRD를 클로드 코드에서 실행할 5단계 프롬프트로 나눈 것
- [구현 계획](docs/superpowers/plans/2026-10-01-todolist.md) — 7개 과제와 각 과제의 테스트까지 적어 둔 작업 순서

## 기능

- 할 일 추가, 수정, 삭제
- 완료 체크
- 카테고리 분류 (업무, 개인, 공부)
- 필터 — 완료 상태(미완료 / 전체 / 완료)와 카테고리를 함께 적용한다
- 진행률 보기 — 전체 진행률 하나와 카테고리별 진행률을 함께 보여준다
- 완료한 할 일 일괄 비우기
- 새로고침해도 유지되는 저장

할 일은 날짜로 묶지 않는다. 하나의 목록에 계속 쌓이고, 완료한 항목도 지우기 전까지 남는다.

자세한 요구사항과 완료 기준은 [PRD.md](PRD.md)에 있다.

## 기술 스택

- HTML, CSS, 순수 자바스크립트
- 라이브러리와 프레임워크 없음
- 파일 구성: `index.html` 하나 (CSS와 자바스크립트를 같은 파일 안에 둔다)

## 실행 방법

구현이 끝나면 `index.html`을 브라우저로 열기만 하면 된다. 설치할 것도, 띄울 서버도 없다.

테스트는 주소 끝에 `?test`를 붙여서 연다. 페이지 아래쪽에 테스트 결과와 `TESTS: n passed, m failed` 한 줄이 나온다. 평소에 쓸 때는 붙이지 않으면 된다.

## 배경

『바이브 코딩』 4장 실습으로 만드는 앱이다. 클로드에게 PRD를 쓰게 하고, 그 PRD를 바탕으로 구현까지 진행하는 과정을 담는다.

이전 버전의 README는 [README-v1.md](README-v1.md)에 남겨 두었다. 그 시점에는 PRD만 있었고 프롬프트 분할 전이라, 진행 과정을 그대로 보존한다.
