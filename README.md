# 할 일 관리 앱

하루 10~20개의 할 일을 관리하는 개인용 웹 앱. **단일 HTML 파일**, 외부 의존성 0.

설치도 가입도 빌드도 없다. `index.html` 하나를 열면 그걸로 끝이다.

## 실행

```bash
python -m http.server 8000
```

그리고 브라우저에서 <http://localhost:8000/index.html> 을 연다.

`index.html` 을 더블클릭해서 `file://` 로 열어도 동작하지만, 브라우저에 따라
`localStorage` 가 막힌다. 막히면 화면 맨 위에 경고 띠가 뜬다 — 모르고 쓰는 일은
없지만, 데이터를 보존하려면 위의 로컬 서버나 GitHub Pages 로 여는 편이 좋다.

## 기능

| | 기능 |
|---|---|
| F1 | 할 일 추가 — 제목 타이핑 후 `Enter` 한 번. 마우스가 필요 없다 |
| F2 | 제자리 수정 — 제목을 누르면 그 줄이 편집 상태가 된다. `Enter` 저장, `Esc` 취소 |
| F3 | 삭제 |
| F4 | 완료 체크 — 완료한 항목은 아래로 내려가 흐려진다 |
| F5 | 카테고리 필터 — 전체 / 업무 / 개인 / 공부 |
| F6 | 진행률 — 헤더의 막대와 숫자. **지금 보고 있는 목록** 기준이다 |
| F7 | 완료 항목 비우기 — 현재 필터에 보이는 완료 항목만 지운다 |
| F8 | 자동 저장 — 변경할 때마다 즉시. 저장 버튼은 없다 |

키보드만으로 전부 조작할 수 있다. 다크 모드와 360px 폭 화면을 지원한다.

### 아직 없는 것

명세(F9~F11)에는 있지만 이 버전에는 넣지 않았다.

- 삭제 되돌리기 (F11)
- 백업 내보내기 / 가져오기 (F10)
- 여러 탭 동시 사용 시 자동 반영 (F9)

**F10 이 없으므로 지금은 백업 수단이 없다.** 브라우저의 "인터넷 사용 기록 삭제"로
쿠키·사이트 데이터를 지우면 할 일이 전부 사라진다.

## 데이터

브라우저의 `localStorage` 에만 저장된다. 서버로 나가는 요청은 **0건** 이다.
기기 간 동기화도 없다 — 이 기기, 이 브라우저에서만 보인다.

| 키 | 언제 생기는가 | 누가 읽는가 |
|---|---|---|
| `할일앱.데이터` | 항상 | 앱 |
| `할일앱.손상된데이터.<시각>` | 저장 데이터가 손상돼 일부를 버릴 때 | 사람만 |

**데이터를 조용히 날리지 않는 것** 이 이 앱의 설계 원칙이다. 저장이 막히거나
저장된 데이터가 깨지면 경고 띠로 알리고, 손상된 원본은 위의 보존용 키에 그대로
남긴다. 개발자 도구(F12)의 Application → Local Storage 에서 꺼낼 수 있다.

## 검증

### 자가검증

<http://localhost:8000/index.html?검증> 을 열면 앱 대신 검증 결과가 나온다.
순수 함수 계층(진행률 경계, 손상 데이터 복구 12유형, 불변식)을 시험하는
**46개 항목** 이다. 평소에는 실행되지 않는다.

맨 위의 `통과 46 / 실패 0` 을 확인하면 된다. 실패가 있으면 실패한 항목만
기대값·실제값과 함께 보여 준다.

### 수동 확인 목록

자가검증이 닿지 않는 것(DOM·브라우저·저장소)은 손으로 확인한다.

1. 추가 → 새로고침 → 남아 있다
2. 수정·삭제·체크·비우기 각각 후 새로고침 → 결과가 유지된다
3. 입력란에서 `Enter` 만으로 추가된다. 추가 후에도 포커스가 입력란에 남는다
4. 카테고리 필터를 바꾸면 목록과 진행률이 함께 바뀐다
5. 업무 필터에서 비우면 업무의 완료 항목만 사라진다
6. 사생활 보호 모드에서 열기 → 경고 띠가 보이고 앱은 그대로 동작한다
7. 개발자 도구로 `할일앱.데이터` 를 망가뜨리고 새로고침 → 경고 띠 +
   `할일앱.손상된데이터.*` 키가 생긴다
8. 키보드만으로 추가·수정·체크·삭제·필터를 전부 수행할 수 있다
9. 360px 폭에서 가로 스크롤이 없다
10. 다크 모드에서 글자가 읽힌다

## 구조

`index.html` 한 파일 안에서 다섯 계층으로 나뉜다. 위 계층은 아래를 모른다.

| 계층 | 책임 |
|---|---|
| 1. 순수 함수 | DOM 도 `localStorage` 도 건드리지 않는다. 자가검증 대상 |
| 2. 저장 | `localStorage` 읽고 쓰기. 모든 접근이 `try`/`catch` |
| 3. 렌더 | 상태를 읽어 화면을 다시 그린다. 상태를 바꾸지 않는다 |
| 4. 사건 | 이벤트 위임. `적용()` 이 상태를 바꾸는 **유일한** 통로 |
| 5. 자가검증 | `?검증` 일 때만 실행 |

핵심은 `적용()` 하나다.

```js
function 적용(새상태) {
  상태 = 새상태;   // 1. 교체
  저장하기(상태);  // 2. 저장
  렌더();          // 3. 그리기
}
```

순수 함수는 새 상태를 만들어 돌려주기만 하고, 저장과 렌더는 `적용()` 이 책임진다.
그래서 "저장했는데 화면이 안 바뀜" 이나 "화면은 바뀌었는데 저장이 안 됨" 이
구조적으로 생길 수 없다.

식별자와 주석은 한글로 쓴다.
